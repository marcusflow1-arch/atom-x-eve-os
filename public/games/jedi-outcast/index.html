    Why do I need the complete files?

    A .nav file contains navigation data. The map itself is in its .bsp file. Characters need their .glm meshes, .gla animations, skins and textures. Screenshots help compare the result but do not replace those assets.

    Use the original archives when possible. Missing files are reported here; no substitute characters or environments are generated.

    Single-player browser port. Use a desktop browser with WebGL and WebAssembly enabled. Alt+Enter toggles fullscreen; Escape releases the mouse.
