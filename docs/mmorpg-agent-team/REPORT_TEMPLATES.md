# Standard task and report formats

## Task packet
**TASK ID:**
**Owner's words:**
**Confirmed game/repo/branch:**
**Assigned specialist & exclusive file ownership:**
**Blueprint section(s):**
**Scope, dependencies, interface contracts:**
**Acceptance criteria and actual test commands:**
**Forbidden edits:**
**Risk and rollback:**
**Approvals explicitly granted:**

## Worker report — handoff to PM
**Task / status / specialist:**
**Exactly what changed and why:**
**Actual inspected files; changed paths:**
**Commit SHA / PR URL / report location (or none):**
**Cross-system interface or schema impact:**
**Exact tests run and observed output:**
**Tests not run and why:**
**Bugs, risks, rollback:**
**PM HANDOFF — integration order; dependent agents to notify; owner decisions needed:**

## Independent QA report
**Task / reviewed commit:**
**Tests run with outputs:**
**PvP/network reconnect, inventory/trade dupe, payment, save-data, cross-game and UI regression coverage:**
**PASS / FAIL / BLOCKED:**
**Reproduction of failures and release recommendation:**

No report is considered transmitted merely because it was written in another chat. PM must observe its content in GitHub or receive it explicitly from the owner.
